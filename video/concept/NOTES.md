# The KPI Stayed Green prototype

## Question

Does one continuous order-token and trace metaphor communicate AYN AL-SIJILL's value more powerfully than six separate dashboard scenes?

## Status

Ready for creative review. This is a throwaway prototype, not production code.

## Artifacts

- `styleframe-01-gap.png`: the successful transaction reaches the missing order junction.
- `styleframe-02-evidence.png`: one trace connects success, missing evidence, and failure.
- `styleframe-03-close.png`: the recovered token and trace resolve into the AYN lens.
- `STYLEFRAME_PROMPTS.md`: the complete image-generation prompt set.
- `animatic-contact-sheet.jpg`: eight representative story beats for quick review.
- `../public/audio/kpi-stayed-green-audio-sketch.wav`: timing-first score and sound sketch.

The styleframes were generated with the built-in image-generation tool. They are visual targets, not production plates. Final UI evidence must use sanitized real product captures.

## Review questions

2. Does the missing order token feel ownable and memorable?

5. Does the final proposition earn the CTA?
