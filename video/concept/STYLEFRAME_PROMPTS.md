# Styleframe prompt set

These are the three image-generation prompts used for the first visual exploration of "The KPI Stayed Green."

## 01. The gap

Create a premium cinematic 16:9 product-film styleframe for an enterprise observability platform. A single luminous mint transaction token travels through a precision-machined smoked-glass channel, then reaches a physically broken junction and begins falling into a deep black void. The successful path behind it remains intact. Materials: dark anodized metal, smoked glass, subtle cobalt-blue rim light, controlled mint emission, sparse atmospheric haze. Camera: low macro three-quarter angle, shallow depth of field, strong negative space, black studio environment. Tone: elegant, forensic, tense, credible, like a global software-company launch film. No people, no dashboards, no readable text, no logos, no generic cyber imagery, no neon overload. Photorealistic 3D, cinematic contrast, restrained palette, crisp geometry.

## 02. The evidence

Create a premium cinematic 16:9 enterprise-software styleframe that continues the same visual world. Three suspended smoked-glass evidence plates sit in a black studio: the left plate contains a precise mint success signal, the center plate contains an exact empty slot where an order event should exist, and the right plate contains a restrained coral failure signal. One thin cobalt trace line travels continuously through all three plates and makes the missing center event unmistakable. Materials: dark anodized metal, smoked glass, subtle reflections, sparse haze. Camera: frontal three-quarter composition with strong depth and negative space. Tone: forensic, intelligent, calm, credible, designed for a high-end software launch film. No people, no cluttered dashboard, no readable interface copy, no logos, no stock-tech cliches. Photorealistic 3D, controlled highlights, precise geometry.

## 03. The close

Create a premium cinematic 16:9 closing styleframe for the same enterprise observability film. In a black studio, the recovered mint transaction token is held at the center of a minimal eye or lens sculpture formed by one continuous cobalt trace line and dark precision-machined metal. The line has resolved from disorder into a confident, simple symbol of visibility. Place the sculpture on the left third and preserve generous clean negative space on the right for final campaign copy. Materials: smoked glass, dark anodized metal, restrained mint core, subtle cobalt edge light, faint volumetric haze. Tone: assured, iconic, trustworthy, quietly dramatic, suitable for a major global software brand. No readable text, no logos, no people, no busy UI, no excessive glow. Photorealistic 3D, cinematic contrast, elegant geometry.
