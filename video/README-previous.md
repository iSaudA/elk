# AYN AL-SIJILL client promotional video

This Remotion composition presents AYN AL-SIJILL as a client-facing operational observability product in 30 seconds:

1. Every KPI represents a client promise.
2. A Ghost Order exposes what ordinary dashboards miss.
3. Correlated identifiers reveal the complete service journey.
4. One trace and one incident card lead to the database timeout.
5. Azure-native controls protect the operational and reporting path.
6. The film closes on the client promise and sales CTA.

## Preview

```bash
. "$HOME/.nvm/nvm.sh" && nvm use default
cd video
npm run studio
```

## Render

```bash
. "$HOME/.nvm/nvm.sh" && nvm use default
cd video
npm run render
```

The final render is written to `out/ayn-al-sijill-client-promo.mp4`. The custom instrumental bed is mixed directly by Remotion. A legacy silent-render script remains available for comparison.
